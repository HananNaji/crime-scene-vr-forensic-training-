# Crime Scene Virtual Reality Simulation for Forensic Science Education

## Overview
A Virtual Reality (VR) training application designed to help forensic science students practice crime scene investigation in a safe and immersive virtual environment.

The project was developed as a graduation project at Birzeit University.

## Key Features
- Immersive virtual crime scene exploration.
- Observational and advanced interactive learning modes.
- Interactive evidence inspection, photography, collection, and tagging.
- Virtual forensic tools, including UV light and fingerprint recovery.
- Evidence documentation and chain-of-custody tracking.
- Procedural feedback and performance scoring.
- Performance reports for students and instructors.
- AI-powered virtual forensic advisor.
- Firebase integration for authentication and data management.

## Technologies Used
- Unity
- C#
- OpenXR
- Firebase
- Large Language Model (LLM) integration
- Virtual Reality (VR)
